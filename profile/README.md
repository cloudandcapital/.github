# Cloud & Capital

**Turning numbers into strategy.**

Cloud & Capital is Diana Molski's home for financial analysis, technology-cost tools, and clear explanations of money and markets. The work connects a finance and FinOps foundation with questions people and small businesses actually need to answer.

This GitHub organization holds the source code and technical documentation. The [website](https://cloudandcapital.com) brings the tools, services, writing and learning resources together.

## Start with the tools

| Project | Purpose | Explore |
| --- | --- | --- |
| [AI Cost Lens](https://github.com/cloudandcapital/ai-cost-lens) | Review AI bills and usage, then connect costs to outcomes when supporting evidence exists | [Open tool](https://lens.cloudandcapital.com) |
| [Cloud Cost Guard](https://github.com/cloudandcapital/cloud-cost-guard) | Read-only cloud, direct-AI and software-spend review with reconciled totals and explicit coverage boundaries | [Open demo](https://guard.cloudandcapital.com) |

Public worked examples in AI Cost Lens and Cloud Cost Guard use illustrative data. Each project describes its supported inputs, evidence requirements, setup and limits.

## Finance and FinOps, in the details

The technical work spans billing data, allocation, reconciliation, variance analysis, anomalies, scenario modeling and unit economics. Supporting tools include:

| Repository | Focus |
| --- | --- |
| [FinOps Lite](https://github.com/cloudandcapital/finops-lite) | Cloud billing analysis and FOCUS export workflows |
| [FinOps Watchdog](https://github.com/cloudandcapital/finops-watchdog) | Baseline-aware cost anomaly analysis |
| [Recovery Economics](https://github.com/cloudandcapital/recovery-economics) | Backup, recovery and resilience cost scenarios |
| [SaaS Cost Analyzer](https://github.com/cloudandcapital/saas-cost-analyzer) | Software costs, license utilization and forecasting |
| [Tech Spend Command Center](https://github.com/cloudandcapital/tech-spend-command-center) | Consolidated technology-cost reporting |
| [Cloud & Capital Analysis Contract](https://github.com/cloudandcapital/cloud-capital-analysis-contract) | Shared analysis contracts and validation |

The goal is a reviewable answer: trace the inputs, explain the calculation, and distinguish a finding from an assumption. See individual repositories for tests, examples, licenses and implementation status.

## Beyond the code

[Business services](https://cloudandcapital.com/services) offer three starting points:

- **Technology Cost Review:** understand supplied software, AI or cloud spending records and identify evidence-supported next steps.
- **AI & Workflow Review:** examine a recurring process and identify a worthwhile improvement.
- **Tool & Automation Setup:** build and test one agreed tool, automation or process.

[Insights](https://cloudandcapital.com/insights) houses educational articles and walkthroughs. [Investing & Trading](https://cloudandcapital.com/learn) is a separate learning path. Markets & Mimosas brings Diana's perspective to money, markets and the business behind the numbers.
